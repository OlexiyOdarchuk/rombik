**Код → блок-схема алгоритму за ДСТУ 19.701-90 (= ГОСТ 19.701-90 = ISO 5807-85).**
Python, C, C++, C#, Java, Pascal → коректна блок-схема: SVG, PNG, PDF, Typst, Excalidraw.

---

## Проєкт виріс у повноцінний продукт

Раніше `rombik` був відкритим рушієм у цьому репозиторії. Він виріс у самостійний
продукт із власним серверним рушієм на Go, акаунтами, галереєю та HTTP-API — тож код
застосунку тепер розвивається приватно, а тут лишився цей опис.

Дякую кожному, хто стежив за репозиторієм і поставив зірочку — ви були з самого початку. ⭐

> **Головне:** базовий функціонал як був, так і лишається **безкоштовним для всіх**.
> Комерційними стали лише «преміум»-зручності (вектор / редактор), а не сама генерація схем.

## Чому це працює і за кордоном

ДСТУ 19.701-90 дослівно відповідає **ISO 5807-85** — тобто умовні позначення схем
коректні не лише для українських викладачів, а й за міжнародним стандартом. Інтерфейс
і підписи в самих схемах доступні українською та англійською.

## Приватність

Сайт будує схему **на сервері**: код надсилається на бекенд лише для генерації й одразу
повертається вам. Я **не зберігаю** ваш код, **не публікую** його і **не передаю**
третім сторонам — він потрібен виключно щоб намалювати схему.

## HTTP API

Потрібен програмний доступ — генерувати схеми зі скриптів, CI чи власних застосунків?
Є **HTTP-API за ключем** (`rk_…`):

- `POST /api/v1/render` — код → `SVG / PNG / PDF / Typst / Excalidraw` (1 кредит за виклик);
- баланс, поповнення, подарунок кредитів другові;
- **OpenAPI 3.1**-специфікація + готовий **скіл для AI-агентів** (щоб самі робили запити).

Документація й створення ключа — на сайті: **[Довідка → API](https://rombik.ishawyha.dev/developers)**.
