# Опції рендера

Перемикачі `layout.Options` — це «галочки» інтерфейсу. Серіалізуються в/з JSON, тож
однаково працюють у CLI (частина) і WASM (усі). Дефолти проставляє `Build`.

```go
type Options struct {
    CallAsProcess bool   `json:"callAsProcess"`
    SingleEnd     bool   `json:"singleEnd"`
    Yes           string `json:"yes"`
    No            string `json:"no"`
    InWord        string `json:"inWord"`
    OutWord       string `json:"outWord"`
    StartText     string `json:"startText"`
    EndText       string `json:"endText"`
    StripTypes    bool   `json:"stripTypes"`
    ReturnAsIO    bool   `json:"returnAsIO"`
}
```

## Перелік

| Опція | Тип | Типово | Що робить | CLI |
|-------|-----|--------|-----------|-----|
| `CallAsProcess` | bool | false | Виклик функції → звичайний прямокутник замість ДСТУ-символу підпрограми. Реалізація — `mapCalls` рекурсивно замінює `ir.Call`→`ir.Process` ще до розкладки. | `-calls-plain` |
| `SingleEnd` | bool | false | Усі `return/raise/exit` + природний вихід → в **один** «Кінець». Інакше — окремий локальний «Кінець» на кожен вихід. → [[Зведення виходів у Кінець]]. | `-single-end` |
| `Yes` | string | «Так» | Підпис гілки «істина» розв'язку (ромб, while). | — |
| `No` | string | «Ні» | Підпис гілки «хиба». | — |
| `InWord` | string | «Ввід» | Слово вводу. `ioText` міняє префікс «Ввід» на обране (напр. «Введення», «Ввести»). | — |
| `OutWord` | string | «Вивід» | Слово виводу (аналогічно). | — |
| `StartText` | string | «Початок» | Текст початкового термінатора. | — |
| `EndText` | string | «Кінець» | Текст кінцевого термінатора. | — |
| `StripTypes` | bool | false | Прибрати тип-анотації: `a: float = 3.1` → `a = 3.1`. Регулярка `typeAnnRe` у `procText`. | — |
| `ReturnAsIO` | bool | false | `return` малювати паралелограмом (InOut) замість прямокутника. | — |

## Як застосовуються

- **`ioText`** (слова вводу/виводу): парсер завжди видає текст із префіксом «Ввід»/
  «Вивід»; layout підмінює префікс на обране слово. Тобто слова — це **рендер-опція**,
  а не парсер.
- **`procText`** (StripTypes): знімає `name: type =` → `name =` регуляркою.
- **`mapCalls`** (CallAsProcess): єдина опція, що змінює **IR** до розкладки; решта
  впливають лише на текст/геометрію під час `place`.
- **Дефолти:** порожній рядок → дефолт (`def(&b.yes, "Так")` тощо в `Build`).

## Чому слова — опції

Різні кафедри хочуть «Ввід» / «Введення» / «Ввести», один «Кінець» чи багато,
показувати типи чи ні. Замість форку — перемикачі. → [[Задум і мотивація]].
