# Розкладка циклів

Чотири види циклів IR і як кожен малюється. Спільна риса — **дуга повернення**
(назад до заголовка) виноситься праворуч на `arcGap`, а вихід — ліворуч і вниз.

## Спільний прийом: loopArcs

`for` і `while` ділять `loopArcs(cx, headHalf, headCy, bodyHalf, bodyBottom, exitLabel)`:

```
   ┌── заголовок (шестикутник/ромб) ──┐
   │            headCy ───────────────┼──┐  ← дуга повернення (праворуч)
   └─────────────┬────────────────────┘  │
   exitLabel ◄───┤ (вихід ліворуч)        │
                 │     [ ТІЛО ]            │
                 │         └──────────────►┘  backX = cx + bodyHalf + arcGap
                 ▼ (продовження)
```

- **Дуга повернення** іде з **центру низу тіла** (спершу трохи вниз — `drop`, тоді
  вбік — щоб не виходити «з кута») праворуч на `backX`, вгору до `headCy`, у **правий
  кут** заголовка. Зі стрілкою.
- **Вихід** — з **лівого кута** заголовка ліворуч на `leftX`, вниз до `contY`, до
  центру. **Без вістря** (`Arrowless`) — голову дасть наступне ребро (вхід у
  фігуру/«Кінець»); підпис `exitLabel`.

Чому вихід без вістря: інакше на вході в наступний блок було б «дві голови» (вістря
виходу + вістря входу). → [[Diagram-модель-геометрії]].

## for — placeFor

`ir.For` → **шестикутник** «початок циклу» з підписом `Spec` («i = 0, n-1, 1»).
Заголовок згори, тіло під ним, `loopArcs` без підпису виходу (у for вихід безумовний).

```go
hw := hexW(n.Spec)
// шестикутник у (cx, top), headCy = top + hexH/2
// тіло: pushLoop → placeBlock → popLoop (збір break-ів)
cont := b.loopArcs(cx, hw/2, headCy, bw/2, bodyExit.Y, "")
b.routeBreaks(cx, cont.Y, brks)   // break-и → на вихід циклу
```

## while — placeWhile

`ir.While` → **ромб-передумова** згори. Гілка «Так» вниз у тіло, дуга повернення
праворуч, гілка «Ні» — вихід ліворуч (`exitLabel = no`).

Майже як `for`, але заголовок — ромб (`diaW`/`diaH`), а вихід підписаний «Ні».

## do-while — placeDoWhile

Ідіома `while True: … if cond: break` → **тіло згори, ромб-умова знизу**:

```
   ────► [ ТІЛО ] ◄─────────────┐  ← повернення вливається в лінію ВХОДУ
            │                    │     (mergeY = top - vGap/2)
            ▼                    │
        ┌─ cond ─┐  Ні           │  backX = cx + bw/2 + arcGap
        │  ромб  ├───────────────┘
        └───┬────┘
        Так │
            ▼ (продовження, contY)
```

- Тіло ставиться першим (`placeBlock` від `top`).
- Ромб під ним; ребро тіло→ромб.
- **«Ні» (повтор)** — дуга праворуч **назад до лінії входу** (`mergeY = top - vGap/2`),
  `Arrowless` — вливається в лінію, а не у фігуру (щоб не було «двох голів»).
- **«Так» (вихід)** — вниз, теж `Arrowless` (голову дасть наступне ребро).

## while True (нескінченний) — placeInfLoop

`while True` із `break`-ами всередині, **без** ромба-умови: лише тіло + **безумовна**
дуга повернення праворуч назад до входу. Вийти можна **тільки через break**.

```go
backX := cx + bw/2 + arcGap
mergeY := top - vGap/2           // вливається в лінію входу
// дуга: центр низу → вниз(drop) → праворуч → вгору → вхід (Arrowless)
contY := bodyExit.Y + vGap
b.routeBreaks(cx, contY, brks)   // саме break дає реальний вихід
```

## break і стек циклів

Усі цикли обгортають тіло в `pushLoop()` / `popLoop()`. Кожен `break` усередині
пишеться у вершину стека `loopBreaks` (`recordBreak`). Після тіла `routeBreaks`
зводить зібрані точки до `contY` (вихід поточного циклу). Стек потрібен для **вкладених
циклів** — break адресується найближчому. → [[Зведення-виходів-у-Кінець]].
