# Розкладка циклів

Чотири види циклів IR і як кожен малюється (`packages/engine/src/layout/place.ts`).
Спільна риса — **дуга повернення** (назад до заголовка) виноситься праворуч на
`arcGap`, а вихід — ліворуч і вниз.

## Спільний прийом: loopArcs

`for` і `while` ділять `loopArcs(cx, headHalf, headCy, startS, startE, bodyBottom, exitLabel, conts)`:

```
   ┌── заголовок (шестикутник/ромб) ──┐
   │            headCy ───────────────┼──┐  ← дуга повернення (праворуч)
   └─────────────┬────────────────────┘  │
   exitLabel ◄───┤ (вихід ліворуч)        │
                 │     [ ТІЛО ]            │
                 │         └──────────────►┘  backX = right + arcGap
                 ▼ (продовження)
```

Праву межу тіла бере `bodyExtent(startS, startE, cx)` — він проходить фігури/ребра,
додані з моменту входу в цикл (зрізи за індексами `startS`/`startE`), і дає реальні
`right`/`left`. Тому дуга гарантовано огинає все тіло.

- **Дуга повернення** іде з **центру низу тіла** (спершу трохи вниз — `drop`, тоді
  вбік — щоб не виходити «з кута») праворуч на `backX`, вгору до `headCy`, у **правий
  кут** заголовка. Зі стрілкою.
- **Вихід** — з **лівого кута** заголовка ліворуч на `leftX`, вниз до `contY`, до
  центру. **Без вістря** (`arrowless`) — голову дасть наступне ребро (вхід у
  фігуру/«Кінець»); підпис `exitLabel`.
- **`continue`** усередині збирається у `conts` і `routeContinues` зводить їх убік до
  `backX` на лінію повернення.

Чому вихід без вістря: інакше на вході в наступний блок було б «дві голови» (вістря
виходу + вістря входу). → [[Diagram-модель-геометрії]].

## for — placeFor

Вузол `for` → **шестикутник** «початок циклу» з підписом `spec` («i = 0, n-1, 1»).
Заголовок згори, тіло під ним, `loopArcs` без підпису виходу (у for вихід безумовний).

```ts
const hw = hexW(n.spec);
// шестикутник у (cx, top), headCy = top + hexH/2
const startS = this.d.shapes.length, startE = this.d.edges.length;
this.pushLoop();
const [bodyExit] = this.placeBlock(n.body, cx, bodyTop);
const [brks, conts] = this.popLoop();
let cont = this.loopArcs(cx, hw / 2, headCy, startS, startE, bodyExit.y, '', conts);
const [c2, ended] = this.placeLoopElse(n.else, cx, cont);
this.routeBreaks(cx, c2.y, brks);   // break-и → на вихід циклу
```

`placeLoopElse` домальовує `for…else`/`while…else`, якщо є.

## while — placeWhile

Вузол `while` → **ромб-передумова** згори. Гілка «Так» вниз у тіло, дуга повернення
праворуч, гілка «Ні» — вихід ліворуч (`exitLabel = no`).

Майже як `for`, але заголовок — ромб (`diaW`/`diaH`), а вихід підписаний «Ні».

### Оптимізація: guard як остання інструкція тіла

Якщо тіло циклу закінчується guard'ом (`if cond: …` без else), `termGuardLast` це
ловить, а `placeGuardLoopBody`/`placeLoopGuard` вмонтовують умову guard'а у дугу
повернення — `«Ні»` guard'а одразу стає дугою повтору, без зайвого довгого треку.

## do-while — placeDoWhile

Ідіома `while True: … if cond: break` → **тіло згори, ромб-умова знизу**:

```
   ────► [ ТІЛО ] ◄─────────────┐  ← повернення вливається в лінію ВХОДУ
            │                    │     (mergeY = top - vGap/2)
            ▼                    │
        ┌─ cond ─┐  Ні           │  backX = right + arcGap
        │  ромб  ├───────────────┘
        └───┬────┘
        Так │
            ▼ (продовження, contY)
```

- Тіло ставиться першим (`placeBlock` від `top`).
- Ромб під ним; ребро тіло→ромб.
- **«Ні» (повтор)** — дуга праворуч **назад до лінії входу** (`mergeY = top - vGap/2`),
  `arrowless` — вливається в лінію, а не у фігуру (щоб не було «двох голів»).
- **«Так» (вихід)** — вниз, теж `arrowless` (голову дасть наступне ребро).

## while True (нескінченний) — placeInfLoop

`while True` із `break`-ами всередині, **без** ромба-умови: лише тіло + **безумовна**
дуга повернення праворуч назад до входу. Вийти можна **тільки через break**.

```ts
const [right] = this.bodyExtent(startS, startE, cx);
const backX = right + arcGap;
const contY = bodyExit.y + vGap;
const mergeY = top - vGap / 2;            // вливається в лінію входу
const drop = bodyExit.y + mergeGap / 2;
// дуга: центр низу → вниз(drop) → праворуч → вгору → вхід (arrowless)
this.routeBreaks(cx, contY, brks);        // саме break дає реальний вихід
```

## break/continue і стек циклів

Усі цикли обгортають тіло в `pushLoop()` / `popLoop()`. Кожен `break` усередині
пишеться у вершину стека `loopBreaks` (`recordBreak`), а `continue` — у `loopConts`
(`recordContinue`). Після тіла `routeBreaks` зводить зібрані break-точки до `contY`
(вихід поточного циклу), а `routeContinues` — до дуги повернення. Стеки потрібні для
**вкладених циклів** — стрибок адресується найближчому. → [[Зведення-виходів-у-Кінець]].
