# A-зірка маршрутизація

Алгоритм у `internal/route` детально. Загальний огляд пакета —
[[Route-маршрутизатор-ребер]]; тут — як саме працює пошук.

## Задача

Прокласти **ортогональну** (лише гориз/верт сегменти) лінію `a → b`, що:

1. не перетинає жодну перешкоду (фігуру),
2. має якомога менше поворотів (прямі лінії гарніші),
3. рахується швидко.

## Крок 1: сітка Ганана

Замість дрібної суцільної сітки беремо лише **значущі лінії**. Для прямокутних
перешкод оптимальний ортогональний шлях завжди можна прокласти по лініях, що проходять
крізь **краї перешкод** і кінці маршруту (це і є *сітка Ганана*).

```go
xs := axis(a.X, b.X, obs, true)   // унікальні X: краї перешкод + кінці
ys := axis(a.Y, b.Y, obs, false)  // унікальні Y
```

Перешкоди роздуваються на `pad=12` (`inflate`) — щоб лінія йшла не впритул, а із
зазором. Фігури, що містять `a` або `b`, з перешкод виключаються (інакше старт
замурований).

Вузли графа — перетини `xs × ys`. Їх мало (O(к-сть фігур²)), тож A* дуже швидкий.

## Крок 2: стан = вузол + вісь руху

Ключова деталь — стан включає **вісь останнього руху** `ax`:

```
state = (j*nx + i) * 3 + ax        // ax: 0 старт, 1 горизонт, 2 вертикаль
```

Навіщо: щоб **штрафувати повороти**. Без цього A* знайшов би шлях тієї ж довжини, але
з купою непотрібних зламів («драбинка»).

## Крок 3: вартість і евристика

```go
cost := |xs[ni]-xs[i]| + |ys[nj]-ys[j]|    // довжина переходу
if ax != 0 && ax != nax { cost += turn }    // turn=24: поворот дорогий
h := |xs[gx]-xs[ni]| + |ys[gy]-ys[nj]|      // манхеттенська відстань до цілі
f := g + h                                   // пріоритет у купі pq
```

- **`cost`** — манхеттенська довжина сегмента.
- **`+turn`** при зміні осі — робить прямі шляхи дешевшими за зигзаги.
- **`h`** — допустима евристика (не переоцінює) → A* дає оптимум.

Рух дозволено лише по **вільних** ребрах сітки: `free(i,j,ni,nj)` = `!blocked(...)`,
а `blocked` перевіряє перетин відрізка з внутрішністю будь-якої перешкоди.

## Крок 4: купа, відновлення, спрощення

- **`pq`** — мінімальна купа (`container/heap`) за `f`.
- Дійшовши до `(gx,gy)`, ідемо по `prev` назад, реверсимо.
- **`simplify`** прибирає колінеарні точки (три на прямій → дві).
- **Фолбек:** не знайшли шлях → Г-подібна ламана `a → (b.X,a.Y) → b`.

## Чому не для всіх ребер

A* — дорожчий за пряму ламану. Більшість ребер схеми (між сусідніми блоками, гілки if,
дуги циклів) **тривіальні** й будуються прямо в [[Layout-рушій-розкладки|layout]].
A* потрібен лише там, де вихід зсередини конструкції може **огинати** інші фігури —
тобто у [[Зведення-виходів-у-Кінець|routeEnds]].
