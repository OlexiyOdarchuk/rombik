# Підтримувані конструкції (Python і C++)

Що парсер `parser/treesitter.ts` ([[Парсер-Python]]) розпізнає, у що зводить і що
ігнорує. Один фронтенд на web-tree-sitter обслуговує **обидві мови** — Python і C++;
ядро (IR → layout → рендери) від мови не залежить. → [[Як-додати-нову-мову]].

## Розпізнається (Python)

| Python | Фігура / вузол | Текст / нюанс |
|--------|----------------|---------------|
| `x = expr` | процес | `x = expr` |
| `x += 1`, `x: int = 0` | процес | augmented / annotated теж |
| `x = input(...)` | ввід (паралелограм) | «Ввід x» (`hasInputNode` ловить `input` будь-де) |
| `print(...)` | вивід | «Вивід …»; порожній `print()` → «Вивід порожнього рядка» |
| `if / elif / else` | ромб + гілки | `elif` = вкладений if; будь-яка глибина |
| `match / case` | ромб(и) | **зводиться в ланцюг if** (3.10+); `case _` → гілка else |
| `for i in range(a,b,c)` | шестикутник | «i = a, b-1, c»; кінець = `stop-1` (`endof`) |
| `for x in iter` (не range) | шестикутник | «x ∈ iter» |
| `for … else:` | + гілка else | виконується після нормального завершення (без break) |
| `while cond:` | ромб-передумова + тіло | + `while … else:` |
| `while True: … if C: break` (останнім) | do-while | ромб-післяумова (`breakIfNode`) |
| `while True:` (break усередині) | нескінченний цикл | без ромба; вихід лише через break |
| `break` | — (без фігури) | стрибок на вихід циклу |
| `continue` | — (без фігури) | стрибок на заголовок циклу |
| `return v` | термінал → «Кінець» | «Повернути v» |
| `raise e` | термінал → «Кінець» | «Помилка: e» |
| `exit()`, `quit()` | термінал → «Кінець» | «Вихід» |
| `x = моя_функція(...)` | підпрограма (риски) | лише для функцій, визначених у файлі (`defined`) |
| `with ... as v:` | блок | «відкрити: …» + тіло |
| `try / except / finally` | блок | тіло `try`, потім гілки обробників `if Виняток …?` і тіло `finally` |
| `def` (зокрема вкладений) | окрема схема | параметри → вхідний паралелограм |

## Розпізнається (C++)

| C++ | Фігура / вузол | Текст / нюанс |
|-----|----------------|---------------|
| `int x = e;`, `x = e;` | процес | `;` прибирається; декларації зводяться до init-declarator'ів |
| `cin >> a >> b;` | ввід | «Ввід a, b» |
| `cout << a << endl;` | вивід | «Вивід …»; рядки в «лапках» |
| `if / else if / else` | ромб + гілки | дужки умови знімаються |
| `switch / case` | ромб(и) | **зводиться в ланцюг if** `subj == val`; default → гілка else |
| `for (init; cond; upd)` | шестикутник | spec = «init, cond, upd» |
| `while (cond)` | ромб-передумова + тіло | |
| `do { … } while (cond);` | do-while | ромб-післяумова |
| `break` / `continue` | — | як у Python |
| `return v;` | термінал → «Кінець» | «Повернути v» |
| `throw e;` | термінал → «Кінець» | «Помилка: e» |
| `exit()` | термінал → «Кінець» | «Вихід» |
| `try / catch` | блок | тіло `try`, потім `if Виняток (тип)?` на кожен `catch` |
| виклик власної функції | підпрограма (риски) | функція, визначена у файлі |
| `<тип> f(параметри) { … }` | окрема схема | параметри → вхідний паралелограм |

## Особливості зведення

- **`continue`** → вузол `continue`. Малюється дугою на заголовок циклу.
  → [[Розкладка-циклів]].
- **`for/else`, `while/else`** → гілка `else` у `for`/`while`: після нормального
  виходу (без break). `unwrapElse` розгортає `else_clause` у тіло.
- **`match`/`switch`** → лоуериться в ланцюг `if` (окремого ДСТУ-символу нема).
- **`try`** прозорий: тіло `try`, далі ланцюг `if Виняток …?` на обробники й тіло
  `finally`.

## Ігнорується

Парсер пропускає (повертає `null`):

| Конструкція | Чому |
|-------------|------|
| `import` / `from … import`, `#include`, `#define` | не частина алгоритму |
| `pass` | порожня дія |
| докстрінги / рядки-вирази (`string`, `concatenated_string`) | коментар, не дія |
| `class` / `class_definition` | методи-дандери — шум; у класи не заходимо |
| коментарі | не дія |
| вкладені `def` у тілі | ідуть **окремими** схемами |

## Особливі правила

- **Кожна функція — окрема схема.** Код поза функціями → схема `main` (або
  `програма`, якщо `main` уже визначена у файлі).
- **Параметри — ввід:** `def f(a, b)` / `T f(a, b)` → перший вузол «Ввід a, b».
- **«Своя» функція vs бібліотечна:** `call` лише для функцій із `defined`
  (зібраних `collectDefinedFunctions`).
- **Обрізання тексту:** один рядок, до 64 символів (`MAXLEN`), далі «…» (`oneline`).
- **f-рядки / рядки:** `f"сума {x}"` та `"txt"` → беруться в «лапки» (`formatArg`).

## Межі

- Конкретні гілки обробки винятків спрощені до «Виняток …?»; «щасливий шлях».
- Comprehension/генератори як керування, декоратори, async-керування — не моделюються.
- Довгі вирази обрізаються до ~64 символів.
