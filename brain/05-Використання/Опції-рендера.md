# Опції рендера

Перемикачі `Options` (`packages/engine/src/layout/options.ts`) — це «галочки»
інтерфейсу. Усі поля необов'язкові; `resolveOptions` заповнює ДСТУ-замовчання й
повертає `ResolvedOptions`, з якими працює розкладка. Однаковий об'єкт використовують
рушій, [[CLI-довідник|CLI]] (підмножина) і [[Фронтенд-SvelteKit|веб]].

```ts
export interface Options {
  callAsProcess?: boolean;
  singleEnd?: boolean;
  yes?: string;
  no?: string;
  inWord?: string;
  outWord?: string;
  startText?: string;
  endText?: string;
  stripTypes?: boolean;
  returnAsIO?: boolean;
  capWord?: string;
  noStart?: boolean;   // внутрішнє: не малювати «Початок» (для частин split)
  noEnd?: boolean;     // внутрішнє: не малювати «Кінець» (для частин split)
}
```

## Перелік

| Опція | Тип | Типово | Що робить | CLI |
|-------|-----|--------|-----------|-----|
| `callAsProcess` | bool | `false` | Виклик функції → звичайний прямокутник замість ДСТУ-символу підпрограми (заміна `call`→`process` ще до розкладки). | — |
| `singleEnd` | bool | `false` | Усі `return/raise/exit` + природний вихід → в **один** «Кінець». Інакше — окремий локальний «Кінець» на кожен вихід. → [[Зведення-виходів-у-Кінець]]. | `--single-end` |
| `yes` | string | «Так» | Підпис гілки «істина» розв'язку (ромб, while). | — |
| `no` | string | «Ні» | Підпис гілки «хиба». | — |
| `inWord` | string | «Ввід» | Слово вводу. `ioText` міняє префікс «Ввід» на обране (напр. «Введення», «Ввести»). | — |
| `outWord` | string | «Вивід» | Слово виводу (аналогічно). | — |
| `startText` | string | «Початок» | Текст початкового термінатора. | — |
| `endText` | string | «Кінець» | Текст кінцевого термінатора. | — |
| `stripTypes` | bool | `false` | Прибрати тип-анотації: `a: float = 3.1` → `a = 3.1`. Регулярка `typeAnnRe` у `procText`. | — |
| `returnAsIO` | bool | `false` | `return` малювати паралелограмом (InOut) замість прямокутника. | — |
| `capWord` | string | `''` | Слово-supplement підпису схеми («Рисунок»/«Рис.»/Figure/своє). | — |
| `noStart` / `noEnd` | bool | `false` | Службові: приховати термінатор «Початок»/«Кінець». Виставляє `splitByHeight` на стиках частин — не для ручного вжитку. | — |

> [!note] Підпис — частково поза Options
> З підпису в `Options` живе лише `capWord`. Решта (текст підпису `caption`, номер
> `figNum`, шаблон `capFormat`) — **поля `Diagram`**, які засіває
> [[Публічний-API-rombik|build]] (ім'я функції + порядковий номер) і перевизначає
> [[Фронтенд-SvelteKit|фронтенд]] (`renderCaption`). → [[Diagram-модель-геометрії]].

## Як застосовуються

- **`ioText`** (слова вводу/виводу): парсер завжди видає текст із префіксом «Ввід»/
  «Вивід»; layout підмінює префікс на обране слово. Тобто слова — це **рендер-опція**,
  а не парсер.
- **`procText`** (`stripTypes`): знімає `name: type =` → `name =` регуляркою `typeAnnRe`.
- **`callAsProcess`**: єдина опція, що змінює **IR** до розкладки (`call`→`process`);
  решта впливають лише на текст/геометрію під час `place`.
- **Дефолти:** `resolveOptions` підставляє замовчання (`yes: o.yes || 'Так'` тощо).

## Чому слова — опції

Різні кафедри хочуть «Ввід» / «Введення» / «Ввести», один «Кінець» чи багато,
показувати типи чи ні. Замість форку — перемикачі. → [[Задум-і-мотивація]].

## Експорт та розбиття

- **Excalidraw**: експорт у `.excalidraw` будується з тієї ж геометрії `Diagram`
  (`renderExcalidraw`), тож окремих полів в `Options` для нього нема.
- **Розбиття схем**: завеликі схеми ріжуться на частини конекторами (кружечки з
  літерами) через `splitByHeight`/`splitFromAst` (`build.ts`). Параметри (як-от
  максимальну висоту `maxH`) передають у ці функції напряму; службово вони лише
  виставляють `noStart`/`noEnd` на стиках, базові `Options` не міняючи. У CLI це
  прапорець `--split N` ([[CLI-довідник]]), у вебі — кнопка «Розбити на частини».
