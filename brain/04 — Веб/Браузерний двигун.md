# Браузерний двигун

Як flowgen працює у браузері **повністю локально** — без сервера, без надсилання коду
кудись. Дві WASM-частини: Pyodide (парсер) і flowgen.wasm (двигун).

> [!important] Нуль довіри до сервера
> Студентський код нікуди не йде. І розбір (Pyodide), і розкладка+рендер (flowgen.wasm)
> відбуваються у вкладці браузера. → [[Задум і мотивація]].

## Дві WASM-частини

```
Python-код (textarea)
   │
   ▼  Pyodide (CPython у WASM) виконує parser.py
AST-JSON  (глобальна _out)
   │
   ▼  flowgen.wasm (Go) — глобальна flowgenGenerate(astJSON, optionsJSON)
{ functions: [{ name, svg, diagram }] }
   │
   ▼  Svelte вставляє svg у DOM + кнопки експорту (SVG/PNG/JSON)
```

- **Pyodide** виконує **той самий** `parser.py`, що й CLI ([[Парсер Python]]) — один
  файл, одне джерело правди.
- **flowgen.wasm** — Go-ядро ([[WASM-міст]]), не імпортує `parser/python` (там
  `os/exec`, недоступний у WASM). Бере вже готовий AST-JSON.

Чому межа саме тут — [[Чому AST-JSON як контракт]], [[Розділення відповідальностей]].

## engine.js — клей

`web/src/lib/engine.js`, дві експортовані функції:

### `warmup(onProgress?)` — ініціалізація (ідемпотентна)

```js
await loadScript(PYODIDE_CDN + 'pyodide.js')
pyodide = await loadPyodide({ indexURL: PYODIDE_CDN })
parserSrc = await fetch(`${base}/parser.py`).then(r => r.text())
await loadScript(`${base}/wasm_exec.js`)
const go = new Go()
const { instance } = await WebAssembly.instantiate(bytes, go.importObject)
go.run(instance)   // НЕ await: Go-main блокується на select{}, лишаючись живим
```

`go.run` не чекають: Go-`main` навмисно висить на `select{}` (`cmd/wasm`), щоб
зареєстрована `flowgenGenerate` лишалась доступною. `initPromise` гарантує, що все це
станеться **один раз** (можна викликати `warmup` заздалегідь для прогріву).

### `generate(code, options, onProgress?)`

```js
await warmup(onProgress)
pyodide.globals.set('src', code)        // parser.py читає глобальну src
pyodide.runPython(parserSrc)            // ast.parse — код НЕ виконується
const astJSON = pyodide.globals.get('_out')
return JSON.parse(globalThis.flowgenGenerate(astJSON, JSON.stringify(options)))
```

Помилки Python чистяться `cleanPyError` (лишаємо останній рядок трейсбеку — суть
`SyntaxError`).

## Артефакти у static/

`build-wasm.sh` (з кореня репо) кладе три файли у `web/static/`:

```bash
GOOS=js GOARCH=wasm go build -o web/static/flowgen.wasm ./cmd/wasm
cp "$(go env GOROOT)/lib/wasm/wasm_exec.js" web/static/
cp internal/parser/python/parser.py web/static/
```

- `flowgen.wasm` — Go-двигун.
- `wasm_exec.js` — рантайм-міст Go↔JS (з Go SDK; **версія має збігатися** з тулчейном).
- `parser.py` — копія парсера для Pyodide (та сама, що вшита в CLI через `//go:embed`).
