# Браузерний рушій

Як rombik працює у браузері **повністю локально** — без сервера, без надсилання коду
кудись. Складових три: Pyodide (парсер) + два WASM-модулі (легкий і растровий).

> [!important] Нуль довіри до сервера
> Студентський код нікуди не йде. І розбір (Pyodide), і розкладка+рендер (WASM)
> відбуваються у вкладці браузера. → [[Задум-і-мотивація]].

## Потік

```
Python-код (CodeMirror-редактор)
   │  Pyodide (CPython у WASM) виконує parser.py
AST-JSON  (глобальна _out)
   │  rombik.wasm → rombikGenerate(astJSON, options)
{ functions: [{ name, svg, typst, diagram }] }
   │  Svelte вставляє svg у DOM; кнопки SVG / Typst / PNG / PDF
   │
   ├─ редагування підпису → rombikRenderOne(diagram, caption) → новий svg (без ре-парсингу)
   └─ експорт PNG/PDF → ЛІНИВО вантажиться rombik-raster.wasm → rombikPng/Pdf
```

- **Pyodide** виконує **той самий** `parser.py`, що й CLI ([[Парсер-Python]]).
- **rombik.wasm** (легкий) — SVG/Typst; **rombik-raster.wasm** (важкий) — PNG/PDF,
  підвантажується на першому експорті. → [[WASM-міст]].

Чому межа саме тут — [[Чому-AST-JSON-як-контракт]], [[Розділення-відповідальностей]].

## engine.js — клей

`web/src/lib/engine.js`. Експортує (приблизно):

| Функція | Призначення |
|---------|-------------|
| `warmup(onProgress?)` | ідемпотентна ініціалізація: Pyodide + легкий WASM + parser.py |
| `generate(code, options, onProgress?)` | код → `{functions:[{name, svg, typst, diagram}]}` або `{error}` |
| `splitSchema(name, maxH, options)` | розбиває довгу схему на кілька частин через з'єднувачі |
| `renderCaption(diagram, cap)` | дешевий ре-рендер підпису → `{svg, typst}` (через `rombikRenderOne`) |
| `renderExcalidraw(diagram)` / `All` | генерує формат **Excalidraw** з `diagram` (JSON) прямо на клієнті |
| `renderPng(diagram, cap, scale)` / `renderPdf(...)` | важкий рендер — **ліниво** вантажить растровий WASM |
| `renderTypstAll(diagrams)` / `renderPdfAll(...)` | експорт усіх схем разом |

```js
// generate — суть
pyodide.globals.set('src', code)
pyodide.runPython(parserSrc)            // ast.parse — код НЕ виконується
const astJSON = pyodide.globals.get('_out')
return JSON.parse(globalThis.rombikGenerate(astJSON, JSON.stringify(options)))
```

`go.run(instance)` не `await`-ять: Go-`main` висить на `select{}`, лишаючи функції
живими. `initPromise` гарантує одноразову ініціалізацію (можна прогріти заздалегідь).
Помилки Python чистяться (лишається суть `SyntaxError`).

## Артефакти у static/

`build-wasm.sh` (з кореня репо) кладе у `web/static/`:

```bash
GOOS=js GOARCH=wasm go build -o web/static/rombik.wasm        ./cmd/wasm
GOOS=js GOARCH=wasm go build -o web/static/rombik-raster.wasm ./cmd/wasmraster
cp "$(go env GOROOT)/lib/wasm/wasm_exec.js" web/static/
cp pkg/parser/python/parser.py web/static/
```

- `rombik.wasm` — легкий рушій (SVG/Typst).
- `rombik-raster.wasm` — важкий растровий (PNG/PDF), lazy.
- `wasm_exec.js` — міст Go↔JS (версія = тулчейн).
- `parser.py` — копія парсера для Pyodide (та сама, що вшита в CLI через `//go:embed`).
