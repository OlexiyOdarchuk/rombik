# Конвеєр обробки

Повний шлях від тексту коду до виводу (SVG/Typst/PNG/PDF), етап за етапом. Приклад —
`examples/grade.py`.

## 0. Вхід

```python
def grade(score):
    name = input("Ваше ім'я: ")
    if score >= 90:
        print("Відмінно")
    else:
        print("Інакше")
```

## 1. Код → AST-JSON  ·  `parser/python`

`python.ParseAll(code)` → `python.AST(code)` запускає `python3 -c parser.py`, код
іде в stdin. `parser.py` робить `ast.parse` (НЕ виконує код) і друкує спрощений JSON:

```json
[{
  "name": "grade",
  "block": {"kind":"block","stmts":[
    {"kind":"io","text":"Ввід score"},          // ← параметр функції
    {"kind":"io","text":"Ввід name"},           // ← input(...)
    {"kind":"if","cond":"score >= 90",
     "then":{"kind":"block","stmts":[{"kind":"io","text":"Вивід «Відмінно»"}]},
     "else":{"kind":"block","stmts":[{"kind":"io","text":"Вивід «Інакше»"}]}}
  ]}
}]
```

Деталі трансформацій — [[Парсер-Python]] і [[Підтримувані-конструкції-Python]].

> [!note] Браузер
> У браузері цей самий `parser.py` виконує Pyodide; результат лежить у глобальній
> `_out`. Жодного `python3`-підпроцесу. → [[Браузерний-двигун]].

## 2. AST-JSON → IR  ·  `parser/astjson`

`astjson.FromJSON(bytes)` десеріалізує JSON у проміжні `astjson.Node` і зводить їх
у [[IR-проміжне-представлення|ir]]:

```
ir.Func{Name:"grade", Body: *ir.Block{Stmts:[
  *ir.IO{Text:"Ввід score"},
  *ir.IO{Text:"Ввід name"},
  *ir.If{Cond:"score >= 90", Then:*ir.Block{…}, Else:*ir.Block{…}},
]}}
```

Вкладені `block`-вузли інлайняться (`ToBlock`). IR — чисте дерево, **без жодних
координат**.

## 3. IR → Diagram  ·  `layout`

`layout.Build(block, opts)`:

1. **`blockSize`** — знизу вгору рахує габарити всього піддерева (скільки місця
   треба). → [[Розкладка-рекурсією-size-і-place]].
2. Ставить термінатор «Початок», ребро вниз.
3. **`placeBlock`/`place`** — згори вниз роздає координати кожному вузлу, додаючи
   `diagram.Shape` і `diagram.Edge`.
4. Збирає всі виходи в `b.ends` і зводить у «Кінець». → [[Зведення-виходів-у-Кінець]].

Результат — `*diagram.Diagram{Shapes, Edges, W, H}` ([[Diagram-модель-геометрії]]).

## 4. Diagram → вихід (кілька бекендів)

Один `Diagram` читають **незалежні** рендери (вибір — за розширенням `-o`):

| Формат | Рендер | Залежності |
|--------|--------|------------|
| `.svg` | `svg.Render(d)` — ребра, тоді ДСТУ-полігони, текст по центру | stdlib. → [[SVG-рендерер]] |
| `.typ` | `typst.Render(d)` — код Typst/CeTZ | stdlib. → [[Typst-рендер]] |
| `.png` | `raster.PNG(d, scale)` — нативний растр | tdewolff/canvas. → [[Растровий-рендер-PNG-PDF]] |
| `.pdf` | `raster.PDF(d)` — нативний вектор | tdewolff/canvas |
| `.json` | `json.MarshalIndent(d)` — сира геометрія | stdlib |

**Жодного зовнішнього бінарника** (раніше PNG робив `rsvg-convert`, PDF — `typst`).

## Хто на якому етапі

| Етап | CLI | Браузер |
|------|-----|---------|
| Код → AST-JSON | `python3` + parser.py | Pyodide + parser.py |
| AST-JSON → IR → Diagram | `cmd/rombik` | `cmd/wasm` (`rombikGenerate`) |
| SVG/Typst | `cmd/rombik` | легкий `rombik.wasm` |
| PNG/PDF | `cmd/rombik` (`raster`) | важкий `rombik-raster.wasm` (lazy) |
| Вивід | файл `.svg/.png/.pdf/.typ/.json` | рядок/base64 у JS → DOM/завантаження |

Ядро (кроки 2–4) **байт-у-байт те саме** в обох — у цьому й суть
[[Розділення-відповідальностей|розділення]]. → [[WASM-міст]].
