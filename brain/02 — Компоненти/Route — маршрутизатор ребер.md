# Route — маршрутизатор ребер

**Пакет:** `internal/route` · **Файл:** `route.go`

Ортогональний маршрутизатор: прокладає лінію між двома точками **в обхід перешкод**
(фігур), так щоб вона не різала блоки й мала якомога менше поворотів. Алгоритм — **A*
по сітці Ганана** зі штрафом за повороти.

> [!note] Де використовується
> Лише у [[Зведення виходів у Кінець|routeEnds]] — щоб звести виходи `return/raise` у
> «Кінець», обходячи проміжні фігури. Звичайні ребра (між сусідніми блоками, гілки if,
> дуги циклів) будуються прямо в [[Layout — рушій розкладки|layout]] як прості ламані,
> без A*.

## API

```go
type Pt struct{ X, Y float64 }
type Rect struct{ X, Y, W, H float64 }   // перешкода (фігура)

func Route(a, b Pt, obstacles []Rect) []Pt
```

Повертає ламану `a → … → b`. Фігури, що **містять** `a` або `b` (джерело/ціль), у
перешкоди не йдуть — інакше старт/фініш були б «замуровані».

## Сітка Ганана

Замість суцільної сітки беремо лише **значущі** координатні лінії: краї всіх перешкод
(після `inflate(pad)`, pad=12) + координати кінців `a`,`b`. `axis()` збирає й сортує
їх окремо по X і Y. Перетин цих ліній і є вузлами графа — їх небагато, тож A* швидкий.

## A* зі станом «вісь руху»

Стан вузла — не лише `(i,j)`, а `(i, j, ax)`, де `ax` ∈ {0 старт, 1 гориз, 2 верт}.
Навіщо `ax`: щоб **штрафувати повороти**.

```go
cost := |Δx| + |Δy|
if ax != 0 && ax != nax { cost += turn }   // turn = 24: зміна напряму дорожча
h := |xs[gx]-xs[ni]| + |ys[gy]-ys[nj]|     // евристика — манхеттенська відстань
```

Штраф `turn=24` змушує A* віддавати перевагу **прямим** лініям з мінімумом зламів —
схема виглядає акуратно, без «драбинок».

`blocked(a,b,obs)` перевіряє, чи axis-aligned відрізок перетинає внутрішність якоїсь
перешкоди (рух дозволено лише по вільних ребрах сітки).

## Відновлення й спрощення

Купа `pq` (мінімальна за `f = g + h`) — стандартний A*. Знайшовши ціль, ідемо по
`prev` назад, реверсимо, тоді **`simplify`** прибирає колінеарні проміжні точки (три
точки на одній прямій → лишаємо дві).

**Фолбек:** якщо шлях не знайдено (`endState < 0`) — повертаємо просту Г-подібну
ламану `a → (b.X, a.Y) → b`.

## Чому окремий пакет

- **Чистий алгоритм** без знання про ДСТУ/SVG — самодостатній, легко тестувати ізольовано.
- Layout користується ним точково; решта схеми не потребує дорогого пошуку.
