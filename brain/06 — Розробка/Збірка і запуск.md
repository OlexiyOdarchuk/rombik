# Збірка і запуск

## Вимоги

| Що | Версія | Для чого |
|----|--------|----------|
| Go | 1.26+ | компіляція двигуна й CLI |
| python3 | 3.9+ | парсер (рідний `ast`, `ast.unparse`) — лише CLI |
| rsvg-convert (librsvg) | будь-яка | вивід PNG — опційно |
| Node.js + npm | сучасна | фронтенд — опційно |

Go-модуль **без зовнішніх залежностей** (лише стандартна бібліотека).

## CLI

```bash
go run ./cmd/rombik                                # демо → out.svg
go run ./cmd/rombik -py examples/grade.py -o grade.svg
go build -o rombik ./cmd/rombik                   # бінарник
```

Повний довідник прапорців — [[CLI — довідник]].

## WASM-артефакти

Скрипт `web/build-wasm.sh` (запускати з кореня або з `web/` — сам перейде в корінь):

```bash
./web/build-wasm.sh
# → web/static/rombik.wasm
# → web/static/wasm_exec.js   (копія з $GOROOT/lib/wasm)
# → web/static/parser.py      (копія internal/parser/python/parser.py)
```

> [!warning] Версія wasm_exec.js
> `wasm_exec.js` береться з того ж Go SDK, що компілює `.wasm`. Якщо оновити Go —
> **перезапусти скрипт**, інакше міст Go↔JS може не зійтися.

Вручну те саме:

```bash
GOOS=js GOARCH=wasm go build -o web/static/rombik.wasm ./cmd/wasm
cp "$(go env GOROOT)/lib/wasm/wasm_exec.js" web/static/
cp internal/parser/python/parser.py web/static/
```

## Фронтенд

```bash
cd web
npm install
npm rebuild esbuild     # npm 11 блокує install-скрипти; esbuild потребує бінарник
npm run dev             # http://localhost:5173
npm run build           # статика → web/build/
```

Перед `npm run dev` мають існувати WASM-артефакти (`build-wasm.sh`), інакше двигун у
браузері не завантажиться. → [[Браузерний двигун]].
