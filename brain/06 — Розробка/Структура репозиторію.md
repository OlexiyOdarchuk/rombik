# Структура репозиторію

```
flowgen/
├── go.mod                  module flowgen, go 1.26, нуль залежностей
├── README.md               стислий опис + швидкий старт
├── .gitignore
│
├── cmd/
│   ├── flowgen/main.go     CLI: файл → SVG/PNG/JSON  → [[CLI — довідник]]
│   └── wasm/main.go        WASM: flowgenGenerate     → [[WASM-міст]]
│
├── internal/
│   ├── parser/
│   │   ├── python/
│   │   │   ├── parser.py   рідний ast → AST-JSON      → [[Парсер Python]]
│   │   │   └── python.go   обгортка (//go:embed, os/exec)
│   │   └── astjson/
│   │       └── astjson.go  AST-JSON → ir              → [[astjson — конвертер]]
│   ├── ir/ir.go            логічне дерево алгоритму   → [[IR — проміжне представлення]]
│   ├── layout/layout.go    ir → diagram (розкладка)   → [[Layout — рушій розкладки]]
│   ├── diagram/diagram.go  модель геометрії           → [[Diagram — модель геометрії]]
│   ├── render/svg/svg.go   diagram → SVG              → [[SVG-рендерер]]
│   └── route/route.go      A* маршрутизатор           → [[Route — маршрутизатор ребер]]
│
├── examples/
│   ├── grade.py            простий приклад (if/else, ввід/вивід)
│   └── course.py           складний (цикли, матриці, try, вкладені функції)
│
├── web/                                               → [[Фронтенд SvelteKit]]
│   ├── build-wasm.sh       збірка WASM-артефактів у static/
│   ├── README.md
│   ├── src/
│   │   ├── lib/engine.js   Pyodide+WASM клей           → [[Браузерний двигун]]
│   │   ├── lib/{Nav,Footer}.svelte
│   │   └── routes/{+page, guide/, app/}
│   └── static/             flowgen.wasm, wasm_exec.js, parser.py (генеровані)
│
└── brain/                  📚 ця документація (Obsidian-vault)
```

## Карта «файл → нотатка»

| Шлях | Нотатка |
|------|---------|
| `cmd/flowgen/main.go` | [[CLI — довідник]] |
| `cmd/wasm/main.go` | [[WASM-міст]] |
| `internal/parser/python/*` | [[Парсер Python]] |
| `internal/parser/astjson/astjson.go` | [[astjson — конвертер]] |
| `internal/ir/ir.go` | [[IR — проміжне представлення]] |
| `internal/layout/layout.go` | [[Layout — рушій розкладки]] + розділ 03 |
| `internal/diagram/diagram.go` | [[Diagram — модель геометрії]] |
| `internal/render/svg/svg.go` | [[SVG-рендерер]] |
| `internal/route/route.go` | [[Route — маршрутизатор ребер]], [[A-зірка маршрутизація]] |
| `web/**` | [[Фронтенд SvelteKit]], [[Браузерний двигун]] |

## Принцип іменування пакетів

Один пакет = одна відповідальність = одна нотатка. Межі залежностей описані в
[[Архітектура — огляд]] і [[Розділення відповідальностей]].
