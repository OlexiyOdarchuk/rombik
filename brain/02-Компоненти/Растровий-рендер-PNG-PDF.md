# Растровий рендер (PNG/PDF)

**Пакет:** `pkg/render/raster` · **Файл:** `raster.go` · шрифт: `font.ttf` (embed)

Малює [[Diagram-модель-геометрії|diagram.Diagram]] **нативно в Go** у PNG (растр) і PDF
(вектор) через бібліотеку `github.com/tdewolff/canvas`. **Без зовнішніх бінарників** —
ні `rsvg-convert`, ні `typst`. Кириличний шрифт вшито в бінарник через `//go:embed`.

> [!important] Навіщо
> Раніше PNG робив `rsvg-convert` (librsvg), а PDF — компілятор `typst`. Користувач мав
> їх ставити. Тепер усе компілюється в один Go-бінарник: запустив — і працює. Ціна —
> одна Go-залежність (`tdewolff/canvas` + транзитивні) і ~400 КБ шрифту в бінарнику. →
> [[Ідеї-та-межі]].

## API

```go
func PNG(d *diagram.Diagram, scale float64) ([]byte, error)  // scale — пікселів/одиницю
func PDF(d *diagram.Diagram) ([]byte, error)                 // одна сторінка
func PDFAll(ds []*diagram.Diagram) ([]byte, error)           // багатосторінковий PDF
```

## Як рендерить

- Будує `canvas.Canvas` і малює ті самі ДСТУ-фігури, що й [[SVG-рендерер|svg.go]]
  (координата-в-координату): прямокутник, ромб, паралелограм (нахил 0.4h), шестикутник
  (скоси 0.5h), стадіон-термінатор, підпрограма з боковими рисками; ребра-ламані з
  вістрями; підписи «Так/Ні»; текст по центру фігур.
- **Переворот осі Y:** canvas має початок унизу-зліва (Y вгору), а діаграма — згори
  (Y вниз); координати перетворюються `(x, H−y)`.
- **Одиниці:** 1 одиниця діаграми = 1 типографський пункт; геометрія масштабується в
  мм (`K = 25.4/72`), шрифт у пунктах. PNG: `DPI(72·scale)` → пікселів = одиниці·scale.
  PDF: сторінка в пунктах = розмір схеми.
- **Підпис** «Рисунок N — …» (`d.CaptionLine()`) малюється під схемою (запас `capGap`).

## Чому tdewolff/canvas

Одна бібліотека дає **і PNG, і PDF** (а ще SVG/EPS) з однієї моделі малювання, з
нормальним текстом і вшитим шрифтом. Альтернатива (rsvg/typst-бінарники) ламала
принцип «один самодостатній бінарник» і не працювала б у WASM.

## У браузері

Растровий рендер важкий, тож винесений в **окремий WASM-модуль** `cmd/wasmraster`
(`rombik-raster.wasm`, ~16 МБ), який фронт підвантажує **ліниво** — лише коли
користувач уперше експортує PNG/PDF. Легкий модуль (SVG/Typst) — окремо. →
[[WASM-міст]], [[Браузерний-двигун]].
