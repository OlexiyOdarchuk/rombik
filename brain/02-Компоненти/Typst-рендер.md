# Typst-рендер

**Пакет:** `pkg/render/typst` · **Файл:** `typst.go`

Малює [[Diagram-модель-геометрії|diagram.Diagram]] у **вихідний код Typst** (через
пакет CeTZ). Це не картинка, а текст `.typ`, який Typst компілює у тісний, чіткий PDF.
Залежності — **лише stdlib** (`fmt`/`strings`): пакет генерує рядок.

## API

```go
func Render(d *diagram.Diagram) string         // один самодостатній .typ-документ
func RenderAll(ds []*diagram.Diagram) string   // багато схем — один документ (по фігурі)
```

## Чому Typst, а не картинка

- **Векторно й чітко.** CeTZ малює ті самі ДСТУ-фігури примітивами Typst → у PDF вони
  ідеальної якості, з нормальним текстом (виділяється, шукається), а не растром.
- **Нативна нумерація.** `figure()` Typst сам нумерує «Рисунок N» і підставляє
  supplement/separator — тож rombik передає лише слово (`CapSupplement`) і роздільник
  (`CapSeparator`), а не готовий рядок. Пор. із растром, де номер вшито в текст
  ([[Diagram-модель-геометрії]]).
- **Вбудовується в курсову.** Студент бере `.typ` і вставляє у свій Typst-документ —
  схема стає частиною роботи з наскрізною нумерацією рисунків.

## Як рендерить

- Преамбула: підключення CeTZ, налаштування supplement/separator для `figure`.
- Кожна фігура `Diagram` → CeTZ-примітив (прямокутник/ромб/паралелограм/шестикутник/
  стадіон/підпрограма) у тих самих координатах, що й [[SVG-рендерер|SVG]].
- Ребра → CeTZ-лінії зі стрілками; підписи «Так/Ні».
- Текст — 14pt sans (Arial/Liberation/DejaVu/Helvetica як fallback). *Раніше був 9pt
  serif — звідси «погані» схеми; виправлено.*
- Сторінка авто-розміру під схему.

## Де використовується

- **CLI:** `-o файл.typ` → `Render`/`RenderAll`. → [[CLI-довідник]].
- **Браузер:** легкий WASM-модуль (`cmd/wasm`) має `rombikTypstAll` для експорту всіх
  схем одним документом. → [[WASM-міст]].
- **PDF без Typst-бінарника:** для тих, хто не має Typst, rombik уміє ще й **прямий**
  PDF через [[Растровий-рендер-PNG-PDF|raster]] — без жодного зовнішнього інструмента.
