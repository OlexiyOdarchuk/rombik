# Diagram — модель геометрії

**Пакет:** `internal/diagram` · **Файл:** `diagram.go`

Геометричний результат розкладки: фігури з координатами + ребра-стрілки. Це
**контракт** між [[Layout-рушій-розкладки|layout]] (виробляє) і
[[SVG-рендерер|render]] (малює). Чиста структура даних, **без логіки й залежностей**.

## Kind — тип фігури

```go
type Kind int
const (
    Terminator Kind = iota // початок/кінець — овал (стадіон)
    Process                // дія — прямокутник
    Decision               // умова — ромб
    InOut                  // ввід/вивід — паралелограм
    Hexagon                // початок циклу (for) — шестикутник
    Predef                 // виклик підпрограми — прямокутник з рисками
)
```

`Kind.String()` дає машинну назву (`terminator`, `process`, `decision`, `io`, `loop`,
`subprogram`), а `MarshalJSON` віддає її **рядком** у JSON — щоб фронтенд читав
«decision», а не число `2`. Зв'язок фігур із ДСТУ — у [[ДСТУ-19.701-90]].

## Структури

```go
type Point struct { X, Y float64 }   // y росте ВНИЗ

type Shape struct {
    Kind Kind
    X, Y, W, H float64   // X,Y — лівий верхній кут; текст центрується
    Text string
}

type Edge struct {
    Points    []Point   // ортогональна ламана
    Label     string    // «Так»/«Ні»/«» (omitempty)
    Arrowless bool       // без вістря (для з'єднань у точці злиття)
}

type Diagram struct {
    Shapes []Shape
    Edges  []Edge
    W, H   float64       // повний розмір полотна
}
```

## Чому `Arrowless`

Часто кілька ребер сходяться в одну точку (злиття гілок if, вхід у «Кінець»). Якби
кожне мало вістря, виходив би «букет стрілок». Тому проміжні ребра роблять без вістря,
а **голову дає лише останнє** ребро, що входить у фігуру. Деталі прийому —
[[Розкладка-if-guard-і-симетрія]], [[Розкладка-циклів]].

## Чому окрема пласка модель

- **Контракт.** Layout і render спілкуються лише через `Diagram`. Можна підмінити
  рендер (PNG, Canvas, інша бібліотека), не чіпаючи розкладку.
- **Серіалізація.** `Diagram` напряму маршалиться в JSON — це й є вихід `-o file.json`
  та поле `diagram` у відповіді WASM (`cmd/wasm`).
- **Нуль залежностей.** Пакет ні від чого не залежить → його імпортують усі, без циклів.

## Координатна система

Початок (0,0) — лівий верхній кут; **y росте вниз** (як у SVG/екранах). Уся схема
симетрична відносно центральної осі `cx = W/2`. Поля навколо — `margin` (44pt),
див. константи в [[Layout-рушій-розкладки]].
