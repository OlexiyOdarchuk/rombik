# Як додати нову мову

Завдяки [[Чому-AST-JSON-як-контракт|AST-JSON як контракту]], додати підтримку нової
мови (C++, JavaScript, Pascal…) — це **лише написати новий фронтенд парсера**. Уся
розкладка, рендер і опції — спільні й безкоштовні.

## Що треба зробити

Новий парсер має видавати **той самий AST-JSON**, що й Python-парсер. І все.

### Контракт виходу

JSON-масив `Func` ([[astjson-конвертер]]):

```json
[
  {
    "name": "ім'я_функції",
    "block": {
      "kind": "block",
      "stmts": [ <вузли> ]
    }
  }
]
```

Вузли (`kind` + потрібні поля):

| kind | поля | сенс |
|------|------|------|
| `process` | `text` | дія |
| `io` | `text` | ввід/вивід (текст із префіксом «Ввід»/«Вивід») |
| `call` | `text` | виклик підпрограми (функція з цього ж файлу) |
| `terminal` | `text` | return/raise/exit |
| `if` | `cond`, `then`, `else` (вузли-block) | розгалуження |
| `for` | `cond` (= Spec «i = a, b, c»), `body` | цикл-лічильник |
| `while` | `cond`, `body` | передумова |
| `dowhile` | `cond`, `body` | післяумова |
| `infloop` | `body` | нескінченний |
| `break` | — | вихід циклу |
| `block` | `stmts` | послідовність (вкладені інлайняться) |

### Куди підключити

1. **CLI:** новий пакет `pkg/parser/<lang>` за зразком `parser/python` —
   видає `[]byte` AST-JSON, тоді `astjson.FromJSON`. Або, якщо парсер зовнішній
   (tree-sitter, окремий бінарник), просто отримай AST-JSON і клич `FromJSON`.
2. **Браузер:** замість Pyodide підвантаж відповідний парсер у WASM
   (напр. web-tree-sitter), видай AST-JSON, передай у `rombikGenerate`
   ([[WASM-міст]]) — рушій не зміниться.

## Що НЕ треба чіпати

- `ir`, `layout`, `diagram`, `render/svg`, `route` — **нічого**.
- Опції рендера ([[Опції-рендера]]) — працюють однаково.

## Конвенції, які варто повторити

Щоб схема виглядала «курсовою» (як у Python-парсері):

- параметри функції → перший `io` «Ввід …»;
- виклик власної функції → `call`, бібліотечний — ні (потрібен аналог `defined`);
- `for` зі скінченним діапазоном → `Spec` «змінна = початок, кінець, крок»;
- довгий текст обрізати (≈64 символи).

Деталі цих рішень — [[Парсер-Python]], [[ДСТУ-19.701-90]].

## Чому це дешево

Межа «AST-JSON» спеціально зроблена мова-агностик і середовище-агностик
([[Розділення-відповідальностей]]). Уся складність (геометрія, ДСТУ, дуги циклів,
зведення в Кінець) живе за цією межею й перевикористовується.
