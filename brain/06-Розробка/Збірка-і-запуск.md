# Збірка і запуск

## Вимоги

| Що | Версія | Для чого |
|----|--------|----------|
| Go | 1.26+ | компіляція рушія, CLI, обох WASM |
| python3 | 3.9+ | парсер (рідний `ast`) — лише CLI (у браузері Pyodide) |
| Node.js + npm | сучасна | фронтенд — опційно |

> [!note] Залежності Go
> Модуль уже **не** «нуль залежностей»: для нативних PNG/PDF додано
> `github.com/tdewolff/canvas` (+ транзитивні). Натомість зник рантайм-залежник
> `rsvg-convert`/`typst`-бінарник. Компроміс — [[Растровий-рендер-PNG-PDF]], [[Ідеї-та-межі]].

## CLI

```bash
go run ./cmd/rombik                                # демо → out.svg
go run ./cmd/rombik -py examples/grade.py -o grade.svg
go run ./cmd/rombik -py examples/course.py -o course.pdf   # нативний PDF
go build -o rombik ./cmd/rombik                    # бінарник
```

Повний довідник прапорців — [[CLI-довідник]]. Готові бінарники на 6 платформ
збирає `release.yml` на тег `v*` → GitHub Releases.

## WASM-артефакти (два модулі)

`web/build-wasm.sh` (з кореня або з `web/`):

```bash
./web/build-wasm.sh
# → web/static/rombik.wasm         (легкий: SVG/Typst, ~4 МБ)
# → web/static/rombik-raster.wasm  (важкий: PNG/PDF, ~16 МБ, lazy)
# → web/static/wasm_exec.js        (копія з $GOROOT/lib/wasm)
# → web/static/parser.py           (копія pkg/parser/python/parser.py)
```

Вручну:

```bash
GOOS=js GOARCH=wasm go build -o web/static/rombik.wasm        ./cmd/wasm
GOOS=js GOARCH=wasm go build -o web/static/rombik-raster.wasm ./cmd/wasmraster
cp "$(go env GOROOT)/lib/wasm/wasm_exec.js" web/static/
cp pkg/parser/python/parser.py web/static/
```

> [!warning] Версія wasm_exec.js
> Береться з того ж Go SDK, що компілює `.wasm`. Оновив Go → **перезапусти скрипт**.

## Фронтенд

```bash
cd web
npm install
npm rebuild esbuild     # npm 11 блокує install-скрипти
npm run dev             # http://localhost:5173
npm run build           # статика → web/build/
```

Перед `npm run dev` згенеруй WASM-артефакти (`build-wasm.sh`), інакше рушій у браузері
не завантажиться. → [[Браузерний-рушій]].

## CI

- **`deploy.yml`** — push у `main`: збирає обидва WASM + фронтенд, деплоїть на GitHub
  Pages (домен `rombik.ishawyha.dev`).
- **`release.yml`** — тег `v*`: крос-компіляція CLI на 6 платформ (Linux/Windows/macOS
  × amd64/arm64), `-trimpath -ldflags "-s -w"`, у GitHub Release.
