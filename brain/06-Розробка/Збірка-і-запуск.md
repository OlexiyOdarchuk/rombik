# Збірка і запуск

Проєкт — **npm-монорепо** (`workspaces`) на TypeScript. Жодного Go, `python3` чи
зовнішніх бінарників. → [[Структура-репозиторію]].

## Вимоги

| Що | Версія | Для чого |
|----|--------|----------|
| Node.js + npm | 22+ | усе: рушій, тести, CLI, веб |
| (нічого більше) | — | парсинг — web-tree-sitter (wasm), рендер — чистий TS |

> [!note] Як виконуються TS-файли
> Рушій і CLI запускаються Node напряму з прапорцем `--experimental-strip-types`
> (типи зрізаються на льоту, без окремого кроку компіляції). `tsc` потрібен лише для
> `typecheck`; для standalone-CLI бандлинг робить esbuild.

## Встановлення

```bash
npm install        # з кореня — піднімає всі workspaces (engine + web)
```

## Рушій і тести

```bash
npm test           # тести @rombik/engine (node:test, golden-еталони)
npm run typecheck  # tsc --noEmit у packages/engine
```

Golden-тести в `packages/engine/test/golden/` — байт-у-байт еталони (SVG/Typst/JSON)
для корпусу `test/corpus/*`. → [[Ідеї-та-межі]].

## CLI

```bash
npm run cli -- examples/grade.py -o grade.svg     # через workspace-скрипт
node --experimental-strip-types tools/rombik.mjs examples/course.py -t typ
```

Standalone-збірка (для роздачі без `node_modules`):

```bash
npm run build:cli                  # esbuild-бандл → dist/rombik.mjs + 3 wasm
node dist/rombik.mjs examples/grade.py -o grade.svg
```

`build:cli` (`tools/build-cli.mjs`) бандлить `tools/rombik.mjs` у самодостатній ESM,
ставить звичайний `#!/usr/bin/env node` шебанг і кладе поруч три wasm:
`web-tree-sitter.wasm`, `tree-sitter-python.wasm`, `tree-sitter-cpp.wasm`. Повний
довідник прапорців — [[CLI-довідник]].

## Фронтенд

```bash
npm run dev        # SvelteKit dev-сервер → http://localhost:5173
npm run build:web  # статика → web/build/
```

Веб бере той самий рушій `@rombik/engine` напряму (без сервера й без WASM-рушія):
web-tree-sitter парсить код → `parseTree` → схеми → SVG/Typst/Excalidraw; PNG/PDF
растеризує сам браузер (SVG → `<canvas>`, PDF через jsPDF). → [[Браузерний-рушій]].

Граматики tree-sitter (`tree-sitter-python.wasm`, `tree-sitter-cpp.wasm`) і ядро
web-tree-sitter лежать у `web/static/` і завантажуються в рантаймі.

## Тести (підсумок)

```bash
npm test           # рушій: парсер, layout, split, svg, typst, excalidraw
```
