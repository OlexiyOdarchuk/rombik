# Ідеї та межі

Що свідомо не зроблено, де межі поточної реалізації і куди можна рости.

## Свідомі рішення (не баги)

- **Деревна розкладка, а не граф.** Структурований код — вкладене дерево, тож
  [[Розкладка-рекурсією-size-і-place|size/place]] достатньо. Довільний goto-потік не
  моделюється (і не має).
- **`try/except` спрощено** до тіла `try`+`else` — «щасливий шлях». →
  [[Підтримувані-конструкції-Python]].
- **Класи пропускаються** (дандери — шум).
- **Власні рендери, а не одна універсальна бібліотека для всього:** SVG/Typst пишуться
  рядком (нуль залежностей, піксельна точність ДСТУ), а растр (PNG/PDF) — через
  tdewolff/canvas. → [[SVG-рендерер]], [[Растровий-рендер-PNG-PDF]].
- **A* лише для зведення в Кінець**, не для всіх ребер. → [[A-зірка-маршрутизація]].
- **Залежність заради self-contained:** нативні PNG/PDF додали Go-залежність
  (`tdewolff/canvas`), але прибрали потребу в зовнішніх `rsvg-convert`/`typst`. Для
  CLI-бінарника й WASM це чистий виграш (користувачу нічого ставити). Ціна — більший
  бінарник і важчий растровий WASM (~16 МБ, тому lazy). → [[WASM-міст]].

## Зроблено з того, що раніше було «куди рости»

- ✅ **Нативні PNG/PDF** без rsvg/typst-бінарників ([[Растровий-рендер-PNG-PDF]]).
- ✅ **Експорт в Excalidraw** на основі тієї ж геометрії на клієнті.
- ✅ **Typst-бекенд** (CeTZ) для вставки в курсову ([[Typst-рендер]]).
- ✅ **Розбиття завеликих схем** на частини за допомогою конекторів через вебінтерфейс.
- ✅ **`continue`, `for/else`, `while/else`, `match`** ([[Підтримувані-конструкції-Python]]).
- ✅ **Підпис «Рисунок N»** наскрізно ([[Diagram-модель-геометрії]]).
- ✅ **Публічний API** `pkg/rombik` для бібліотечного вжитку.
- ✅ **Темна тема, вкладки опцій + Svelte 5 ($state, $effect)** у вебі ([[Фронтенд-SvelteKit]]).

## Поточні межі

- Конкретні `except`-гілки не малюються; comprehension/декоратори/async-керування — теж.
- Текст блоку обрізається до ~64 символів.
- Лише Python як вхід (архітектура готова до інших — [[Як-додати-нову-мову]]).
- Тести: є для `route`, парсера, частково layout/rombik; візуального snapshot-покриття
  схем поки нема.

## Куди рости

- **Нові мови** через AST-JSON ([[Як-додати-нову-мову]]): C++/tree-sitter, JS, Pascal.
- **Snapshot-тести** розкладки (золоті SVG/JSON для `examples/*`).
- **Схуднути в залежностях:** canvas важкий; можливо, легший растровий шлях або менший
  растровий WASM.
- **Більше нюансів match/case** (зараз — простий if-ланцюг).

## Філософія

> Схема має виглядати **як у методичці**, а не «теоретично правильно». Кожне спрощення
> служить читабельності курсової схеми. → [[Задум-і-мотивація]].
