# Ідеї та межі

Що свідомо не зроблено, де межі поточної реалізації і куди можна рости.

## Свідомі рішення (не баги)

- **Деревна розкладка, а не граф.** Структурований код — вкладене дерево, тож
  [[Розкладка-рекурсією-size-і-place|size/place]] достатньо. Довільний потік
  (goto, складні `continue`) не моделюється — і не має, бо схеми будуються зі
  структурованого коду.
- **`try/except` спрощено** до тіла `try`+`else`. Діаграма показує «щасливий шлях»;
  обробка винятків не малюється — інакше схема вибухає гілками. → [[Підтримувані-конструкції-Python]].
- **Класи пропускаються.** Методи-дандери — шум; кожен корисний метод можна винести у
  функцію.
- **Власний SVG-рендер**, а не бібліотека — заради піксельної точності ДСТУ. →
  [[SVG-рендерер]].
- **A* лише для зведення в Кінець**, не для всіх ребер — решта тривіальні. →
  [[A-зірка-маршрутизація]].

## Поточні межі

- Не моделюються: `match/case`, comprehension як керування, декоратори, async-керування,
  конкретні `except`-гілки, `continue`.
- Текст блоку обрізається до ~64 символів (`oneline`/MAXLEN) — довгі вирази втрачають хвіст.
- Лише Python як вхід (хоча архітектура готова до інших — [[Як-додати-нову-мову]]).
- Тести: є для `route`; ядро розкладки покрите слабо.

## Куди рости

- **Нові мови** через той самий AST-JSON ([[Як-додати-нову-мову]]): C++/tree-sitter,
  JS, Pascal.
- **Інші бекенди рендера** з тієї ж `Diagram`: PNG напряму (без rsvg), Canvas, PDF,
  TikZ/LaTeX. Контракт уже є ([[Diagram-модель-геометрії]]).
- **Більше конструкцій:** `match/case` → багатогілковий розв'язок; `continue` → дуга на
  заголовок циклу.
- **Тести розкладки:** золоті SVG/JSON для `examples/*` (snapshot-тести).
- **A* ширше:** застосувати маршрутизатор і до інших «довгих» ребер, якщо знадобиться
  обхід фігур.

## Філософія

> Схема має виглядати **як у методичці**, а не «теоретично правильно». Кожне спрощення
> (try, класи, обрізання тексту) служить читабельності курсової схеми, а не повноті
> моделювання. → [[Задум-і-мотивація]].
