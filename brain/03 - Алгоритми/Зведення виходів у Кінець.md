# Зведення виходів у Кінець

Як усі шляхи, що завершують функцію (`return/raise/exit` і природний вихід), доходять
до термінатора «Кінець». І як `break` виходить із циклу.

## Два режими: single-end vs per-exit

Опція `SingleEnd` ([[Опції рендера]]):

| Режим | Поведінка | Що за ДСТУ |
|-------|-----------|------------|
| **per-exit** (типово) | кожен `return/raise/exit` малює **свій локальний «Кінець»** | допустимо |
| **single-end** (`-single-end`) | усі виходи зводяться в **ОДИН** «Кінець» унизу | теж допустимо |

Обидва режими — за ДСТУ; вибір за смаком викладача.

## placeTerminal — return/raise/exit

```go
func (b *build) placeTerminal(text string, cx, top float64) (Point, bool) {
    exit := b.leaf(kind, text, cx, top)   // прямокутник (або паралелограм за ReturnAsIO)
    if b.singleEnd {
        b.ends = append(b.ends, exit)     // → у спільний Кінець
        return exit, true
    }
    // per-exit: одразу свій локальний «Кінець» під блоком
    b.d.Shapes = append(..., term(cx, endTop, b.endText))
    return ..., true
}
```

Повертає `ended=true` — після `return` решта блоку недосяжна
([[Розкладка рекурсією - size і place]]).

## Природний вихід

Якщо тіло функції **не** завершилось `return`'ом, його кінцева точка теж іде в
`b.ends` (у `Build`). Тобто `ends` містить усі точки, які треба звести в «Кінець».

## routeEnds — зведення в «Кінець»

```go
func (b *build) routeEnds(cx, kY float64) {
    obs := b.rects()                       // усі фігури як перешкоди
    if len(b.ends) == 1 {                  // один вихід — ребро прямо в Кінець
        b.d.Edges = append(..., routed(route.Route(ends[0], {cx,kY}, obs), false))
        return
    }
    // кілька: кожен — у точку збору над Кінцем (Arrowless), тоді ОДНА стрілка вниз
    jy := kY - vGap
    for _, e := range b.ends {
        ... route.Route(e, {cx, jy}, obs) ... // Arrowless
    }
    b.d.Edges = append(..., edge({cx, jy}, {cx, kY}))  // спільна стрілка в Кінець
}
```

- **Маршрутизація з обходом фігур** — через [[Route - маршрутизатор ребер|route.Route]]
  (A*), бо вихід десь зсередини може огинати інші блоки. → [[A-зірка маршрутизація]].
- **Один Кінець, багато входів:** усі вливаються в спільну точку збору `jy` без
  вістрів, а вниз у «Кінець» іде єдина стрілка — щоб не було «букета голів»
  ([[Diagram - модель геометрії]]).
- Якщо виходів кілька, «Кінець» опускають на `mergeGap` нижче — запас під шину збору,
  щоб вона не різала фігури.

## break — routeBreaks

`break` не має фігури. Точка break реєструється (`recordBreak`) у вершину стека
`loopBreaks` поточного циклу. Після тіла:

```go
func (b *build) routeBreaks(cx, contY float64, pts []Point) {
    for _, p := range pts {
        if p.X ≈ cx { /* прямо вниз до contY */ }
        else        { /* p → (p.X, contY) → (cx, contY) */ }  // вбік і вниз
    }
}
```

Усі break-и циклу зводяться до `contY` — точки **продовження після циклу**. Стек
`loopBreaks` забезпечує правильну адресацію у **вкладених** циклах (break → найближчий
цикл). → [[Розкладка циклів]].

## contentBottom

Де ставити «Кінець» по вертикалі: `contentBottom(d)` шукає найнижчу точку серед усіх
фігур і ребер, додає `vGap` (+`mergeGap` якщо виходів багато). Так «Кінець» завжди
нижче всього вмісту.
